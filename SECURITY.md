# Security and Data Reports

## Reporting

Please report security issues, exposed credentials, privacy concerns, or requests to correct/remove dashboard data by email at [taifu@taifua.com](mailto:taifu@taifua.com). Include the affected URL or entity, the observed problem, and enough context to reproduce it. Do not publish credentials or sensitive personal information in a public issue.

## Scope

The maintained version is the current `main` branch and the deployment at `https://v2ex.taifua.com/`. Reports about the crawler, static dashboard, deployment configuration, or generated-data exposure are in scope. Vulnerabilities in V2EX itself should be reported to V2EX, not this project.

## Data Handling

The dashboard analyzes publicly accessible V2EX pages and does not infer sensitive personal attributes. Member details cover only a limited set of active accounts and favor monthly or annual aggregates over precise recent activity. Reasonable correction or removal requests will be reviewed for a subsequent data release.

The MIT license applies to project source code; it does not grant rights to third-party V2EX content or data. Cookies, proxy credentials, SQLite databases, and crawl logs must remain outside Git.
