# V2EX 看板路线图

路线图只记录已经评估、但尚未全部交付的工作。新增功能必须回答明确问题，并先定义数据口径、缺失值和验收方式。

## P0：数据质量

- **已建立：标题关键词治理。** 频次只作为候选门槛；结合语义一致性、时间变化、作者与节点覆盖、集中度、既有关键词重合度和代表标题进行人工确认。
- **持续扩展：关键词回归集。** 当前 124 条覆盖关键实体、领域词和高风险歧义；已提供真实标题分层抽样和人工批准后追加的工作流，后续逐步扩展到约 500 条，不用机器建议或低价值合成样例凑数量。
- **已增强：质量漂移审计。** 候选报告同时输出关键词覆盖率、每个标题平均关键词数、与上次审计相比的候选变化、近期份额、峰值周期、作者/节点集中度、既有关键词重合度和标题样例；每次更新数据后继续人工复核。

## P1：内容与构建

- **已完成：代表评论。** 话题与标题关键词按当前范围逐年保留感谢 Top 10 后合并，节点按全部历史逐年合并并最多展示 100 条；选择年份或月份后切换到该期 Top 10 或自适应 Top 3/5/10，并保留原文、作者、时间、感谢数和来源帖子。
- **已有基础：客观讨论指标。** 生命周期页已展示回复率、首条回复速度、参与用户、楼主参与率和讨论结构；新增指标前先确认是否提供额外解释力。
- **已完成首阶段：增量产物。** 内容相同的 JSON 不重复写入；源数据只有成员变化时复用实体评论；代表评论使用小型 SQLite 部分索引避免扫描无感谢评论。下一步再评估按脏周期和脏实体更新聚合事实。
- **已完成：数据与源码解耦。** 大体积生成 JSON 已移出 Git，通过版本化 Release、仓库锁文件、SHA-256、缓存复用和原子安装独立交付。
- **已评估：代表帖子实体去重。** 现有 466.9 MiB JSON 的跨文件理论重复上界为 28.7%，但不增加请求即可消除的单分片内部重复仅约 9.2 MiB（2.0%）；收益不足以承担实体引用和前端拼装复杂度，暂不改生产契约。
- **已完成试验：外链域名变化。** 约 30% 的有效帖子正文或标题含站外链接；近一年 GitHub、应用分发和研究站点增长较明显，传统技术内容站点回落。未分类域名仍占较大比例，当前保留为离线审计，不增加公开视图。

## P2：待 P1 验收后启动

- 标题意图分类：求助、经验、分享、招聘、交易等，先建立人工标注样本。
- 突发与同期特色关键词：区分长期高频和阶段性异常增长，不重复现有 Top 排名。
- 正文意图或语义聚类：只有先建立人工标注集和可重复的离线评估，才重新考虑；不再从词面共现直接上线。

## 暂不实施

不做简单关键词匹配包装出的情绪或经济指数、全站词云、自动生成的大规模 AI 点评、全量成员画像，以及没有明确性能收益的前端框架重写。正文与评论的已审核词共现试验亦已撤回：宽泛词和样本偏差导致增量信息有限，后续只在有人工标注和可重复评估时再考虑语义或意图分析。
