# 指标与筛选口径

看板使用固定、可解释的质量门槛筛除无效或弱信号，再通过 Top N、分页和局部展开控制信息密度。门槛不随数据分布自动漂移，以保持跨期结果可复现、可比较。

## 当前规则

| 对象 | 规则 | 原因 |
| --- | --- | --- |
| 未知互动值 | `-1` 不参与排序 | 未知不等于零 |
| 月度、年度收藏帖子 | 收藏数至少 5，Top 100 | 只呈现具有明确收藏价值的帖子；无结果时隐藏“收藏”排序 |
| 月度、年度感谢帖子 | 感谢数至少 5，Top 100 | 只呈现明确获得社区认可的帖子；无结果时隐藏“感谢”排序 |
| 月度、年度点击与综合帖子 | 每项独立 Top 100 | 榜尾已有自然区分度，不再增加人为门槛 |
| 代表评论 | 感谢数至少 3 | 排除偶发弱信号，并控制评论正文分片体积 |
| 全站热门帖子、评论 | 分别 Top 200、Top 500 | 全站榜单的自然榜尾已足够高，不另设门槛 |
| 节点详情 | 累计至少 50 个有效帖子 | 保证趋势和关联结构具有基本样本量 |
| 标题关键词 | 通常至少 20 个标题、15 位作者、3 个节点 | 同时约束频次和覆盖面，降低单一用户或节点噪声 |
| 低频领域词 | 至少 10 个标题、8 位作者、3 个节点并经人工确认 | 补充新产品和专业实体，不进入主趋势排名 |
| 月度代表内容 | 按当月相关帖子量保留 Top 3、5 或 10 | 兼顾低频对象覆盖和高频对象信息量 |

推广节点不进入代表内容候选；异常账号 `usdc` 不进入感谢榜单。实体详情中的代表帖子以相关性和综合互动优先，不额外设置收藏或感谢门槛，避免低频话题、关键词和节点失去样本。

## 维护原则

新增或调整门槛前，应检查保留数量、空白周期、榜尾值和生成数据体积。不要为了填满榜单降低质量要求，也不要仅为减少页面项目而提高数据门槛；页面密度应优先通过默认 Top 10、分页和移动端展开控制。

快速检查当前生成结果：

```bash
.venv/bin/python scripts/audit_analysis_thresholds.py
```

扫描源数据库并比较感谢数候选门槛：

```bash
.venv/bin/python scripts/audit_analysis_thresholds.py --scan-source
```
